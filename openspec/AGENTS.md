# AGENTS.md

This repository uses OpenSpec for planning. Before implementing, read the
active change under `openspec/changes/`.

- Specs (source of truth): `openspec/specs/`
- Active changes: `openspec/changes/<name>/`
- Artifact order: `proposal.md` -> `specs/` -> `design.md` -> `tasks.md`

Work through the `tasks.md` checkboxes during implementation, checking them off
as each completes.
